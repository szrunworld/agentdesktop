## 首轮验收发现并已修复

- `window list` 默认混入大量离屏服务窗口 → 默认只列在屏窗口，`--all` / `includeOffscreen` 才包含离屏。
- 中文应用名导致表格错位 → 按终端显示宽度对齐。
- `doctor` 长检查名与说明粘连 → 列宽自适应。
- SwiftPM resource bundle 在 .app 内的 CLI / 宿主里找不到（开发机上靠构建路径兜底，换机器会崩）→ 契约改为生成进代码（`scripts/generate-runtime-contract.sh`），测试保证与 `contracts/` 一致。

## 未覆盖 / 留给后续

- 两个产品宿主同时启动的真机竞争：单元测试已覆盖 flock 拒绝；真机上第二个宿主会先在引擎 control.sock 上失败并弹窗（既有行为），未在用户屏幕上触发。
- `runtime start` 拉起已安装产品：只在单元测试里验证（真机会启动用户的产品宿主，本次不做）。
- Windows（W1）、写路径（PR2）、MCP/SDK（PR3）不在本 PR。
