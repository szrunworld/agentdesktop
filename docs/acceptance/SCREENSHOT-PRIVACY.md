# 验收截图隐私规则

Kevin 2026-10-08 裁决：验收截图会被推送到 GitHub，提交前必须做隐私审查。截图是验收证据，脱敏时不能破坏要证明的内容。

## 拍摄

- 只截被测应用自己的窗口：`screencapture -x -o -l <windowId>`。不截整块显示器，也不截用户的主屏。
- 画面里如果出现整块显示器（虚拟显示器的预览、缩略图、Desktop 观察图），macOS 会在每块显示器上都画一份菜单栏，里面有用户的前台应用名、菜单栏应用图标和时间。这一条要裁掉或涂黑，**内嵌的每一层都算**。
- 不使用用户自己的应用、窗口或文件做验收对象；只用测试副本自己的中立探针。

## 提交前检查

1. 逐张查看：其他应用的窗口或标题、窗口选择列表、菜单栏、通知、Dock、文件路径、用户名、设备名（例如「某某的 iPhone」「MacBook Pro」）、账号、聊天内容、密钥。
2. 有就涂黑，或者换一张；用不透明色块，不用模糊。
3. 检查元数据：`strings -n 5 <file> | grep -iE "<用户名>|iphone|macbook|/Users/"`。
4. 在 PR 里写明「截图已做隐私审查」，以及做了哪些涂黑。
