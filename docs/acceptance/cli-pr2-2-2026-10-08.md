## 已知限制 / 后续

- 外部取消 exec 的 Run 后，子程序本身继续运行（只是再也不能输入）；`session exec` 的 Ctrl-C 会转给子程序并取消 Run。
- `wait` 每次轮询都会重新读取窗口元素，会使更早快照的元素引用失效（按设计），应使用 `wait` 返回的 snapshotId。
- 同一进程跨 Desktop 的冲突域按 pid 串行；更细的冲突域（同一 App 的多实例等）待需要时扩展。
- 引擎 control.sock 仍可绕过 Runtime；待引擎代码迁入本仓库后收口。
