## 三、真实测试的运行方式（#141 合入后）

真实 Runtime 测试只连测试自己启动的子进程（[12-test-runtime-isolation.md](12-test-runtime-isolation.md)）：

```sh
swift build --product AgentDesktopApp
ACP_TEST_RUNTIME_BINARY="$(swift build --show-bin-path)/AgentDesktopApp" swift test --filter RuntimeBridgeSmokeTests
```

不接受外部端点或 PID；测试目录统一在 `$TMPDIR/acp-tests-<pid>-<uuid>` 下，进程退出时删除。
