# 首发功能矩阵

依据路线文档第五节。每项分四个状态：契约已定义、代码已实现、自动验证通过、目标环境验收通过。只有四项都是「是」才算完成；状态随 PR 更新。

| 编号 | 功能 | 契约 | 代码 | 自动验证 | 目标机验收 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| F01 | 安装与首次使用 | 否 | 否 | 否 | 否 | 阶段 0 只有本地自签的 App 包和构建清单；向导、权限检测、模型检测未开始 |
| F02 | 工作屏与应用 | 部分 | 部分 | 否 | 部分 | 引擎 CLI 的 create/list/destroy/resize/window 契约已有；宿主有预览、尺寸、归属与释放菜单；阶段 0 在目标机验证了 create/list/destroy、截图、放置窗口、交还与搬回（屏幕录制与辅助功能已授权） |
| F03 | 新建任务 | 否 | 否 | 否 | 否 | 等 C03 的任务读模型与 C06 的中性参考 Agent |
| F04 | 任务工作台 | 否 | 否 | 否 | 否 | 主窗口与 Dock 入口随此项进入（路线决定 1） |
| F05 | 控制与人工接管 | 否 | 否 | 否 | 否 | 依赖 C03 按任务取消/暂停意图 |
| F06 | 待处理与权限 | 否 | 否 | 否 | 否 | 依赖 C04 审批绑定与确认链修复 |
| F07 | 模型配置与用量 | 否 | 否 | 否 | 否 | 依赖 C04 调用前预算 |
| F08 | 结果与历史 | 否 | 否 | 否 | 否 | 依赖 C05 通用产物契约 |
| F09 | Agent 安装与管理 | 否 | 否 | 否 | 否 | 依赖 C06 |
| F10 | 设置与支持 | 否 | 否 | 否 | 否 | 构建清单 `build.json` 是版本与来源的起点 |
